# Site Web Personnel - Quarto

Ce dépôt contient le code source et les fichiers de rendu de mon site Web personnel développé dans le cadre du cours STT-4230 / STT-6230 (Université Laval, Automne 2026).

## Informations sur le projet
- **Étudiante :** Ninive Cunha Vigeant
- **Dépôt source GitHub :** [<https://github.com/ninivecv/Site-Quarto-personnel>]
- **Site web publié :** [<https://ninivecv.github.io/Site-Quarto-personnel>]

## Contenu du site
Le site est structuré en plusieurs pages (générées via Quarto) :
- **Présentation et Intérêts :** Profil académique et centres d'intérêt en science des données.
- **Parcours et Compétences :** Synthèse de mon parcours universitaire et professionnel. 
- **Expériences :** Détail de mes stages et expériences de travail.
- **Réalisations :** 
  - *Réalisation 1 (Portfolio d'apprentissages) :* Suivi d'un cours universitaire (STT-4230/STT-6230).
  - *Réalisation 2 (Projet de session) :* Application interactive Shiny sur les listes d'attente chirurgicales et urgences au Québec.
- **Déclaration IA :** Transparence sur l'utilisation des assistants de rédaction et de code.
